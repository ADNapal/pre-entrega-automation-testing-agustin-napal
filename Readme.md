Proposito: proyecto para curso de Automatizacion QA 2026. Pagina de prueba objetivo https://www.saucedemo.com/.

Tecnologias: Escrito en python y utilizando las librerias de pytest.

Para instalar la herramientea "pytest" se abre la terminal y se ingresa el comando 'pip install pytest', para ver la version instalada se utiliza el comando 'pytest --version'.
Para instalar la herramienta "selenium" se abre la terminal y se ingresa el comando 'pip install selenum', para ver la version instalada se utiliza el comando 'pip show selenium'.
Para instalar la herramienta "webdriver-manager" se abre la terminal y se ingresa el comando 'pip install webdriver-manager'


Para ejecutar las pruebas ingrese en la terminal el comando "pytest -v". Genera un reporte en html al terminar la ejecucion de los test.
